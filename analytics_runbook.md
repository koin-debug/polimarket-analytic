# 📘 Руководство по аналитическому комплексу (Analytics Runbook)

Данный документ содержит полное описание всех исследовательских скриптов, локальных баз данных (кэшей) и отчётных файлов проекта. Он не затрагивает исполняющего бота (`bot_main.py` / `polymarket_engine.py`) и служит справочником для анализа рынка, проверки торговых гипотез и аудита чужих профилей Polymarket.

## 🚀 2. Каталог скриптов и инструкции по запуску

### Блок 1. Исследование поведения рынка и серий свечей (Binance / Bybit)

#### 1. `streaks.py` — Главный загрузчик кэша и поиск монохромных серий
* **Назначение:** Ядро исторической базы. Скачивает с биржи Binance свечи за 2021–2026 годы, ведёт локальный кэш и находит все непрерывные серии из $N$ одноцветных свечей подряд. Умеет умно обновлять кэш (докачивать только свежий «хвост»).
* **Поддерживаемые активы:** BTC, ETH, SOL и любые пары к USDT.
* **Входные данные:** При отсутствии кэша качает данные из сети; при наличии — мгновенно читает локальные CSV.
* **Выходные файлы:** `btc_m15_full_cache.csv`, `eth_m15_full_cache.csv`, а также отчёты `btc_m15_streaks_8plus_2021_2026.xlsx`.
* **Запуск:**
  ```powershell
  python streaks.py
  # В интерактивном меню выбрать монету (1 - BTC, 2 - ETH) и минимальную длину серии (по умолчанию 8)
  ```

---

#### 2. `post_streak_analysis.py` — Анализ реакции рынка после затяжной серии
* **Назначение:** Проверяет гипотезу: *«Что происходит со следующими $K$ свечами после того, как сформировалась серия из $N$ свечей одного цвета?»*. Считает вероятность разворота на 1-й следующей свече, процент откатов и распределение цветов в заданном горизонте.
* **Входные данные:** `btc_m15_full_cache.csv` (или пятиминутки `btc_m5_full_cache.csv`).
* **Выходные файлы:** `streak_{N}_horizon_{K}.xlsx` (или консольный вывод).
* **Примеры запуска:**
  ```powershell
  # Базовый запуск (серия 10 свечей, смотрим следующие 6 свечей):
  python post_streak_analysis.py

  # Пользовательские параметры (серия из 8 свечей, горизонт 20 свечей):
  python post_streak_analysis.py --streak 8 --horizon 20

  # Анализ по пятиминуткам:
  python post_streak_analysis.py --cache btc_m5_full_cache.csv --streak 12 --horizon 10
  ```

---

#### 3. `time_zone_streak_analysis.py` — Кластеризация серий по часам и сессиям
* **Назначение:** Проверяет распределение длинных серий по времени суток (UTC), дням недели и сессиям (Азия, Европа, США). Проводит тест согласия Пирсона ($\chi^2$), определяя, случайно ли возникают серии или есть аномальные торговые часы.
* **Входные данные:** `btc_m15_full_cache.csv`.
* **Выходные файлы:** `time_zones_streak_{N}.xlsx` с почасовой сеткой и тепловой картой.
* **Примеры запуска:**
  ```powershell
  # Проверить серии из 10 свечей:
  python time_zone_streak_analysis.py --streak 10

  # Проверить серии из 8 свечей:
  python time_zone_streak_analysis.py --streak 8
  ```

---

#### 4. `volatility_atr.py` — Расчёт исторической волатильности и размаха свечей
* **Назначение:** Рассчитывает средний истинный диапазон (ATR) по годам (2021–2026) в долларах ($) и в процентах (%). Позволяет объективно сравнивать волатильность рынка при цене BTC в $25 000 и $100 000.
* **Входные данные:** `btc_m15_full_cache.csv`.
* **Выходные файлы:** Excel-таблица с динамикой волатильности по годам и месяцам.
* **Запуск:**
  ```powershell
  python volatility_atr.py
  ```

---

#### 5. `atr_normalized_analysis.py` — Тест гипотезы «Истощение диапазона»
* **Назначение:** Оценивает размах серии относительно текущего ATR(14). Разделяет серии на категории («Умеренный ход», «Сильный вынос», «Экстремальный ход > 3.5x ATR») и вычисляет, возрастает ли вероятность разворота при аномальном выносе цены.
* **Входные данные:** `btc_m15_full_cache.csv`.
* **Выходные файлы:** `atr_analysis_streak_{N}.xlsx`.
* **Примеры запуска:**
  ```powershell
  python atr_normalized_analysis.py --streak 8
  python atr_normalized_analysis.py --streak 10 --atr 14
  ```

---

### Блок 2. Аудит и парсинг профилей Polymarket

#### 6. `fetch_vlabs_trades.py` — Выгрузка истории сделок через Data API
* **Назначение:** Подключается к публичному API Polymarket (`/activity`) и забирает массив реальных сделок любого кошелька.
* **Входные данные:** Адрес кошелька Polygon (`0x...`).
* **Выходные файлы:** `vlabs_trades_1000.xlsx` (или `{username}_trades_{limit}.xlsx`).
* **Примеры запуска:**
  ```powershell
  # Выгрузка последних сделок аккаунта vlabs:
  python fetch_vlabs_trades.py --address 0xc77cd7a4864825aedcc0f4bfbb38539846d205c5 --limit 500
  ```

---

#### 7. `fast_enrich_with_cache.py` — Турбо-расчёт исходов и PnL по выгруженным сделкам
* **Назначение:** Берет «сырой» Excel-файл со сделками (`vlabs_trades_1000.xlsx`), мгновенно сверяет время каждого пула с локальным кэшем свечей (`btc_m15_full_cache.csv` / `btc_m5_full_cache.csv`), определяет факт победы или поражения, рассчитывает чистый PnL каждой ставки и красит строки в зелёный/красный цвет.
* **Скорость:** Отрабатывает за 1–2 секунды за счёт кэша (в отличие от старого поштучного скрипта).
* **Входные данные:** `vlabs_trades_1000.xlsx` + локальные CSV свечей.
* **Выходные файлы:** `vlabs_trades_with_pnl_calculated.xlsx`.
* **Запуск:**
  ```powershell
  python fast_enrich_with_cache.py
  ```
