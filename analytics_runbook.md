# 📘 Руководство по аналитическому комплексу (Analytics Runbook)

Данный документ содержит актуальное описание всех исследовательских скриптов, локальных баз данных (кэшей) и отчётных файлов репозитория `polimarket-analytic`. Комплекс предназначен для статистического анализа рынка (BTC/ETH) и ончейн-аудита кошельков Polymarket.

---

## 🗂 1. Архитектура комплекса

Инструментарий разделён на **два независимых контура**:

```text
                              ┌──────────────────────────────────────────────┐
                              │           АНАЛИТИЧЕСКИЙ КОМПЛЕКС             │
                              └──────────────────────┬───────────────────────┘
                                                     │
                 ┌───────────────────────────────────┴───────────────────────────────────┐
                 ▼                                                                       ▼
   [БЛОК 1: Исследование рынка и серий]                             [БЛОК 2: Ончейн-аудит Polymarket]
   • streaks.py (База свечей + Серии)                               • fetch_onchain_tokens_v2.py (Выгрузка сделок)

```

## 🚀 3. Каталог скриптов и инструкции по запуску

### Блок 1. Исследование поведения рынка и серий свечей (Binance)

#### 1. `streaks.py` — Загрузчик кэша и поиск монохромных серий
* **Назначение:** Скачивает с Binance Vision исторические свечи (с 2021 года), инкрементально докачивает свежий «хвост» при повторных запусках и находит все непрерывные серии из $N$ одноцветных свечей подряд с замером внутрисерийных откатов.
* **Поддерживаемые активы:** BTC, ETH, SOL и любые пары к USDT (таймфреймы `15m` и `5m`).
* **Выходные файлы:** `{coin}_{tf}_streaks_cache.csv` (или обновление существующего `{coin}_m15_full_cache.csv`) и Excel-отчёт `{coin}_{tf}_streaks_{N}plus_report.xlsx`.
* **Запуск:**
  ```powershell
  python streaks.py
  # В интерактивном меню выбрать:
  # 1) Монету (1 — BTC, 2 — ETH или тикер вручную)
  # 2) Таймфрейм (1 — 15m, 2 — 5m)
  # 3) Минимальную длину серии (по умолчанию 8 для 15m, 10 для 5m)
  ```

---

#### 2. `post_streak_analysis.py` — Анализ реакции рынка после затяжной серии
* **Назначение:** Проверяет, что происходит на следующих $K$ свечах после формирования серии из $N$ одноцветных свечей. Считает процент разворотов на 1-й свече, вероятность хотя бы одного отката на горизонте и суммарный ход цены.
* **Входные данные:** `btc_m15_full_cache.csv` (можно указать другой кэш через `--cache`).
* **Выходные файлы:** `streak_{N}_horizon_{K}.xlsx`.
* **Примеры запуска:**
  ```powershell
  # Базовый запуск (серия 10 свечей, горизонт 20 свечей):
  python post_streak_analysis.py

  # Серия из 8 свечей, смотрим следующие 6 свечей:
  python post_streak_analysis.py --streak 8 --horizon 6

  # Анализ по пятиминуткам или по ETH:
  python post_streak_analysis.py --cache eth_m15_full_cache.csv --streak 8 --horizon 12
  ```

---

#### 3. `time_zone_streak_analysis.py` — Кластеризация серий по часам и сессиям
* **Назначение:** Распределяет найденные серии по часам суток (UTC), дням недели и торговым сессиям (Азия, Европа, США). Проводит тест согласия Пирсона ($\chi^2$), проверяя, является ли распределение случайным шумом или есть выраженные часы активности.
* **Входные данные:** `btc_m15_full_cache.csv` (или другой файл через `--cache`).
* **Выходные файлы:** `time_zones_streak_{N}.xlsx`.
* **Примеры запуска:**
  ```powershell
  python time_zone_streak_analysis.py --streak 8
  python time_zone_streak_analysis.py --streak 10 --cache eth_m15_full_cache.csv
  ```

---

#### 4. `volatility_atr.py` — Расчёт исторической волатильности (D1 / M15 / M5)
* **Назначение:** Рассчитывает средний истинный диапазон (ATR) по годам (2021–2026) в долларах ($) и в процентах (%). Позволяет объективно сравнивать волатильность при разной стоимости актива. При необходимости подтягивает 5-минутные свечи.
* **Входные данные:** `btc_m15_full_cache.csv` / `eth_m15_full_cache.csv` (докачивает недостающее из сети).
* **Выходные файлы:** `{coin}_daily_intraday_atr_2021_2026.xlsx`.
* **Запуск:**
  ```powershell
  python volatility_atr.py
  # В меню выбрать монету (1 — BTC, 2 — ETH) и необходимость включения M5 [y/N]
  ```

---

#### 5. `atr_normalized_analysis.py` — Тест гипотезы «Истощение диапазона»
* **Назначение:** Оценивает чистый ценовой ход серии относительно текущего $\text{ATR}(14)$ (`Ход / [N * ATR]`). Делит серии на 4 категории скорости (от слабого дрейфа `< 0.6x` до взрывного выноса `> 1.5x`) и проверяет, растёт ли винрейт контртренда при аномальном выносе цены.
* **Входные данные:** `btc_m15_full_cache.csv` (или другой файл через `--cache`).
* **Выходные файлы:** `norm_atr_streak_{N}.xlsx`.
* **Примеры запуска:**
  ```powershell
  python atr_normalized_analysis.py --streak 8
  python atr_normalized_analysis.py --streak 10 --atr 14 --cache eth_m15_full_cache.csv
  ```

### Блок 2. Ончейн-аудит кошельков Polymarket (2-этапный пайплайн)

#### 6. `fetch_onchain_tokens_v2.py` — [Этап 1] Выгрузка ончейн-ставок кошелька
* **Назначение:** Скачивает через Etherscan API V2 (Polygon, `chainid=137`) все покупки токенов исходов (`token1155tx`) и фактические списания USDC (`tokentx`) для любого кошелька, обходя лимиты в 10 000 записей. Автоматически определяет названия рынков и направление ставки (`Up`/`Down`) через Gamma API и сохраняет их в локальный кэш `tokens_market_cache.json`.
* **Входные данные:** Адрес кошелька Polygon (`--address`) и ключ Etherscan API V2 (`--apikey`).
* **Выходные файлы:** `vlabs_all_onchain_trades.xlsx` (или имя, заданное через `--out`) + обновление `tokens_market_cache.json`.
* **Запуск:**
  ```powershell
  python fetch_onchain_tokens_v2.py --address 0xАДРЕС_КОШЕЛЬКА --apikey ВАШ_ETHERSCAN_API_KEY --out target_wallet_raw.xlsx
  ```

---

#### 7. `analyze_trades_pnl.py` — [Этап 2] Сквозной расчёт PnL и колен Мартингейла
* **Назначение:** Берёт Excel-выгрузку первого этапа, сортирует сделки строго по хронологии, сверяет время экспирации каждого пула с локальным кэшем свечей Binance (`btc_m15_full_cache.csv` или докачивает недостающие пачками в кэш) и формирует финальный финансовый отчёт.
* **Структура отчёта (4 листа):**
  1. *Журнал сделок (PnL)* — построчный аудит с ценой входа, фактом свечи, выплатой, ROI и накопленным балансом.
  2. *Анализ серий (Мартингейл)* — группировка сделок в цепочки до победы, длина колена и расход на серию.
  3. *Динамика по месяцам* — винрейт, оборот, чистый PnL и Profit Factor по месяцам.
  4. *Сводная аналитика* — общие итоговые показатели кошелька.
* **Запуск:**
  ```powershell
  # Запуск со стандартными именами (vlabs_all_onchain_trades.xlsx -> vlabs_final_pnl_report.xlsx):
  python analyze_trades_pnl.py

  # Запуск для произвольного файла:
  python analyze_trades_pnl.py --file target_wallet_raw.xlsx --out target_wallet_final_report.xlsx
  ```

## 🧹 4. Регламент обслуживания и очистки

1. **Архивация устаревших скриптов:**
   Скрипт `fast_enrich_with_cache.py` (ранняя версия расчёта PnL для выгрузок из веб-интерфейса) заменён на `analyze_trades_pnl.py`. Переместите его в архив, чтобы не путаться:

   ```powershell
   Move-Item fast_enrich_with_cache.py arc/
   ```

   Все аналитические скрипты Блока 1 и `analyze_trades_pnl.py` по умолчанию обращаются к файлу `btc_m15_full_cache.csv`. Если вы запускаете `streaks.py` на чистом компьютере, переименуйте созданный им `btc_15m_streaks_cache.csv` в `btc_m15_full_cache.csv` (либо передавайте имя файла через флаг `--cache`).
